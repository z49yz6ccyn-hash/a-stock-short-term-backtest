# A股短线交易策略回测系统

## 项目简介
基于Python的A股短线交易策略回测系统，包含28套量化策略、多策略共振选股、优选个股筛选、Flask Web控制台。

## 核心功能
- 28套短线交易策略回测（含大盘趋势过滤、样本外分段验证）
- 多策略共振选股（11套盈利策略同时命中计数）
- 二次筛选优选个股（A/B/C三级评分体系）
- Flask Web控制台（收益看板、后端控制、文件产物、优选个股）
- 每日收盘信号自动生成

## 快速开始

```bash
# 安装依赖
pip install flask akshare pandas numpy

# 1. 下载行情数据（约15分钟，4进程并发）
python -X utf8 update_data.py

# 2. 运行28套策略回测（约30分钟，支持断点续传）
python -X utf8 backtest_engine_v2.py

# 3. 多策略共振选股
python -X utf8 resonance_screen.py --top 30

# 4. 二次筛选优选个股
python -X utf8 screen_filter.py

# 5. 生成优选个股页面
python -X utf8 gen_stock_pick_html.py

# 6. 启动Web控制台
cd webapp && python app.py
# 访问 http://127.0.0.1:5000
```

## 交易纪律

1. **仓位管理**：单只个股仓位不超过总资金20%，同时持有不超过5只
2. **止损纪律**：严格按策略止损位执行，亏损达到止损比例立即卖出，不补仓摊平
3. **止盈纪律**：达到止盈位分批卖出，至少卖出一半锁定利润
4. **持有周期**：严格按策略持有天数执行，到期未达止盈也卖出
5. **大盘过滤**：上证综指跌破MA20时空仓观望，不逆势操作
6. **共振优先**：优先选择5重以上共振的个股，共振数越多置信度越高
7. **涨幅控制**：当日涨幅超过8%的个股不追高，等待回调
8. **ST股谨慎**：ST/*ST个股仓位减半，严格止损

## 回测参数
- 初始资金：100万
- 佣金：0.03%
- 印花税：0.1%
- 滑点：0.1%
- 单策略最多持仓：5只
- 每只个股仓位：Top3等权
- 回测区间：2025-09-01 至 2026-09-11
